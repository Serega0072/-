# Русский календарь

**Русский календарь** — Android-приложение для планирования личного времени с поддержкой тёмной темы и push-уведомлений. Позволяет добавлять события на конкретные дни, просматривать расписание на месяц вперёд и получать напоминания в нужное время. Все данные хранятся локально на устройстве.

## О проекте

Приложение выполнено в современном стиле с градиентным интерфейсом: фиолетово-изумрудная палитра в светлой теме и тёмно-фиолетовая в тёмной. Интерфейс полностью на русском языке. Разработано в рамках учебной практики по специальности «Информационные системы и программирование».

## Стек

- Java
- Android SDK (minSdk 26, targetSdk 34)
- Android Studio
- XML-разметка (без Jetpack Compose)
- SharedPreferences + Gson
- AlarmManager
- ConstraintLayout / GridLayout / RecyclerView / CardView
- Material Components

## Возможности

- Splash-экран с градиентным фоном и кнопкой запуска
- Месячный календарь с навигацией вперёд и назад
- Красные точки на днях у которых есть события
- Выделение текущего дня и выбранного дня
- Добавление событий с указанием времени (ЧЧ:ММ) и названия
- Валидация формата времени
- Привязка события к выбранной дате
- Список событий на выбранный день в виде сетки карточек
- Удаление конкретного события долгим нажатием
- Удаление всех прошедших событий одной кнопкой
- Push-уведомления в точное указанное время через AlarmManager
- Восстановление уведомлений после перезагрузки устройства
- Переключение тёмной темы через настройки
- Включение и отключение уведомлений через настройки
- Экран полезных советов по планированию
- Полная поддержка тёмной темы на всех экранах

## Экраны

| Экран | Назначение |
|---|---|
| SplashActivity | Заставка с кнопкой «Начать» |
| MainActivity | Календарь + список событий на день |
| AddEventActivity | Форма добавления события |
| SettingsActivity | Тема и уведомления |
| TipsActivity | Три карточки с советами |
